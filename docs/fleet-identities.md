# Fleet Identities (running agents as themselves)

> How hermes-agent runs an AI fleet of 5 identities on a 238K-star repo
> without eroding trust — and how to set up yours as you scale past
> "the workflows run as github-actions".

## Why dedicated identities

The kit's default fleet (ai-review, sweeper, autofix) runs as the
repo's `github-actions` bot via `GITHUB_TOKEN`. That's correct for
tier 0–1: zero setup, scoped permissions, automatic revocation.

The upstream lesson at scale: **fleet actions must be attributable and
revocable**. When 17,000+ triage comments flow through one identity,
you need to answer "which automation did this?" in one glance, and
kill one agent's credentials without touching the others. Upstream's
fleet:

| Identity | Role | Self-labeling |
|---|---|---|
| `Enough1122` | code reviewer (2,152 reviews) | "AI code review — automated review for reference" |
| `alt-glitch` | triage/clustering (17,720 items) | "This was generated by AI during triage" |
| `hermes-sweeper` | verdicts (7,149) | HTML markers under maintainer account |
| `hermes-seaeye[bot]` | autofix (484 PRs) | GitHub App identity |
| maintainer accounts | merge/close authority | humans, always |

## Your promotion path

1. **GitHub App for automation** (recommended over user accounts): create
   an App, install on the org, use the kit's `get-app-token` action to
   mint 1-hour installation tokens (already in this tier). The App IS the
   identity — `your-org/ai-reviewer[bot]`. Revocable per-installation.
2. **Machine user accounts only if an App can't do it** (e.g., the
   sweeper needs a "user-shaped" presence): create one account per role,
   one scoped PAT each, stored as DIFFERENT secrets (`SWEEPER_TOKEN`,
   `REVIEWER_TOKEN`). Never reuse one token across roles; never run the
   fleet under a maintainer's personal token (upstream's sweeper posts
   under the maintainer account — it works, but it makes attribution
   forensic instead of obvious; the markers carry the truth).
3. **Disclosure discipline** — the part that earns community trust:
   - Every automated comment self-labels in the first line
   - Every automated action carries an HTML marker
     (`<!-- ai-review:sha=… -->`, `<!-- sweeper:verdict=… -->`)
   - The AGENTS.md rubric states what each agent may and may not decide
4. **Attribution ethics**: agents acting under a human's identity is
   that human's call (their commits, their trailers). Agents acting as
   themselves label loudly. Never blur the two.

## Secrets layout at tier 2

| Secret | Used by | Notes |
|---|---|---|
| `AI_REVIEW_API_KEY` | reviewer + sweeper | LLM provider key |
| `AUTOFIX_TOKEN` | autofix | App token or PAT (contents:write) so autofix pushes re-trigger CI |
| `RELEASE_TOKEN` | release | protected `release` environment |
| `APP_CLIENT_ID` / `APP_PRIVATE_KEY` | get-app-token | if you mint App tokens |

Rotate on any suspicion — App tokens make this a non-event (they expire
in an hour anyway; the private key rotation is one secret update).
