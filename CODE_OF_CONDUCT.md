# Code of Conduct

## Our Pledge

We want this project to be a place where anyone can report a bug, propose
a change, or ask a question without friction. Be direct, be technical, be
kind — in that order, and all three.

Note on automation: parts of this project's triage and review pipeline
are automated (an AI reviewer and triage sweeper operate on pull requests
and issues). Their output is advisory and audited; if an automated action
ever feels wrong or unfair, flag it to a maintainer — humans own every
policy here, and reopening is always free.

## Our Standards

Behavior that moves the project forward:

* Assuming good faith, especially with newcomers and non-native speakers
* Evidence over assertions — repro steps, logs, `git log -S` citations
* Focusing criticism on code and decisions, never on people
* Gracefully accepting corrective feedback (including from automation)

Behavior that gets moderated:

* Harassment, personal attacks, or discriminatory language
* Deliberately hostile or unconstructive feedback
* Spam, astroturfing, or bad-faith contribution farming
* Publishing others' private information without consent

## Enforcement

Report issues privately via the security contact in
[SECURITY.md](SECURITY.md) — conduct reports are handled privately, never
in public issues. Maintainers will respond within 72 hours. Consequences range
from a warning to a permanent ban, at maintainer discretion, with the
decision recorded (decisions are revisable — appeal by email).
